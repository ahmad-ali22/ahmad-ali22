A Workspace → Projects → Tasks hierarchy supporting Kanban, Calendar, and Table views, with role-based access spanning five permission levels (superAdmin, admin, moderator, member, client) and real-time group chat with a message approval workflow.

- Designed and implemented all nine Firestore data models across six feature layers, with consistent Provider-based service patterns (explicit ID scoping, state reset on logout)
- Wrote and iterated Firestore security rules to enforce role-based data access
- Diagnosed and fixed a recurring silent-failure bug where create operations failed due to unpopulated provider state, resolved by restructuring affected screens to StatefulWidget
- Built the complete authentication layer (email/password and Google Sign-In) with persistent login via AuthWrapper
- Built a six-file responsive theming system (fonts, spacing, colors, components) based on a 390x844 design reference, used consistently across the entire app
